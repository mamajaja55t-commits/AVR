AR Animals & Spaceship - Hiro Marker

วิธีใช้:
1. แตกไฟล์ ZIP
2. เปิด index.html ผ่าน Live Server หรือ HTTPS
3. เปิดกล้องและอนุญาต Camera
4. ส่องกล้องไปที่ Hiro Marker
5. จะพบ ควาย ช้าง ม้า และยานอวกาศ
6. กดปุ่มเพื่อให้แต่ละตัววิ่ง/ยานบิน
7. กด "หยุดทั้งหมด" เพื่อหยุดทุกตัว

หมายเหตุ:
- ใช้ A-Frame + AR.js ผ่าน CDN
- แนะนำให้เปิดผ่าน HTTPS หรือ localhost
- ต้องมีอินเทอร์เน็ตเพื่อโหลดไลบรารี CDN
